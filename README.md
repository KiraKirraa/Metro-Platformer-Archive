# Kira's Metro Platformer Archive
This README exists mostly so I don't forget where to put things. There are no restrictions on the use of materials in this repository at the moment, feel free to use any textures/models/art/code where you like, credit is apprectiated.
## Description
Repository of assets and important files to be used for transfer and organization of assets related to the metro platformer
## Structure
### Assets Folder
All 3D models, textures, shaders 2D art, etc. organized the same as game's assets folder
```
environment (textures and modular parts for the environment)
    atlases (textures/shaders used by multiple objects)
    models (models/shaders that use atlases and unique textures)
props (unique 3d models and textures for individual objects)
characters (models, textures, animations for characters)
key_art (press-kit type assets)
(will probably add more for 2d art later)
```
### Code Folder
All important code for the project, not necessarily organized with game's folders
```
no folders currently
```
### Planning Folder
All notes, concepts, and other planning materials related to the game
